# Nearby Places Android App

## Project Overview
Nearby Places is an Android application developed using Java and Android Studio that helps users find nearby locations based on their current GPS location. The application integrates Google Maps and location services to display nearby places on an interactive map.

## Features
- Current location detection using GPS
- Google Maps integration
- Search nearby Hospitals
- Search nearby Schools
- Search nearby Hotels
- Search nearby Restaurants
- Search nearby Banks
- Display location markers on the map
- Real-time location-based search


## Technologies Used
- Java
- Android Studio
- Google Maps API
- Android Location Services
- Gradle
- XML

## System Architecture
1. User grants location permission.
2. Application obtains the current GPS coordinates.
3. User selects a place category.
4. Google Maps API retrieves nearby locations.
5. Results are displayed as markers on the map.

## Installation
1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Configure the Google Maps API key.
5. Run the application on an Android device or emulator.
